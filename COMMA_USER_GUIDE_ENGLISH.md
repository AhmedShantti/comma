## ABOUT THIS SYSTEM

### What Is COMMA?

COMMA is a modern Point of Sale (POS) and restaurant management system designed for cafes and lounges. It helps you manage orders, tables, menu items, payments, and track business performance.

### Who Uses COMMA?

- **Managers:** Oversee operations, manage staff, and view reports
- **Cashiers:** Create orders, process payments, and print receipts
- **Customers:** Order from tables using QR code without logging in
- **Administrators:** Configure the entire system and manage user accounts

### Main Benefits

1. **Easy Ordering** - Customers order directly from their table using a QR code
2. **Fast Payment** - Accept multiple payment methods (cash, card, wallet)
3. **Automatic Receipts** - Generate and print receipts instantly
4. **Business Insights** - View detailed reports and analytics
5. **Table Management** - Track which tables are occupied and their orders
6. **Menu Control** - Easily update prices, items, and availability
7. **Multi-Language** - Supports English and Arabic

### Problems It Solves

- Reduce order errors by letting customers order directly
- Speed up payment processing with multiple payment options
- Eliminate paper order slips with digital tracking
- Understand business performance with detailed analytics
- Manage staff shifts and track revenue

## GETTING STARTED

1. Open the COMMA application
2. Enter your **Username** in the first field

4. Click the **Sign In** button

**To change your password (if available):**
1. Look for your profile menu (usually in the top-right corner)
2. Select "Settings" or "Account Settings"

## COMPLETE FEATURES GUIDE

### FEATURE 1: CREATE & MANAGE ORDERS

#### Purpose
Orders are how you record what customers want to buy. Every sale starts with creating an order.

#### Who Can Access
- Cashiers can create orders for customers
- Managers can create orders
- Administrators have full access

#### Step-by-Step: Creating a New Order

**Step 1: Go to Orders**
1. Click "Orders" in the sidebar menu
2. You'll see a list of existing orders
3. Click the "Create Order" or "+" button

**Step 2: Choose Order Type**
When creating an order, select one of three types:
- **Dine-In:** Customer eating at a table
- **Takeaway:** Customer taking food to-go
- **Delivery:** Delivering to a customer's address

**Step 3: Select or Create Table/Customer**

For **Dine-In orders:**
- Select the table number from the list
- System shows if table is occupied or available

For **Takeaway or Delivery:**
- Enter the customer's name
- For delivery, enter the delivery address (optional)

**Step 4: Add Items**
1. Click "Add Item" button
2. Find the item in the menu
3. Select the item
4. Choose quantity (how many)
5. Select variants if available (e.g., size: small/medium/large)
6. Choose add-ons if available (e.g., extra cheese, no sauce)
7. Add notes if needed (e.g., "no onions")
8. Click "Add to Order"
9. Repeat for each item you want to add

**Step 5: Review Items**
- See all items in the order
- Item prices and total appear
- Can remove items if needed by clicking the X

**Step 6: Apply Discount (Optional)**
1. Click "Add Discount" if available
2. Enter discount type (fixed amount or percentage)
3. Enter discount value
4. Click "Apply"

**Step 7: Confirm Order**
- Review everything
- Click "Save Order" or "Confirm"
- Order is now in the system

**Step 8: Process Payment**
- Click "Checkout"
- Select payment method:
  - Cash
  - Card
  - Wallet
  - Online
- Enter amount received (for cash)
- System calculates change
- Click "Process Payment"

**Step 9: Receipt**
- Receipt generates automatically
- Can print immediately
- Can export as PDF
- Customer receives copy

#### Expected Results
- Order appears in the orders list
- Status shows as "Open"
- Table is marked as occupied (for dine-in)
- Kitchen receives order notification
- Receipt is available to print

#### Example Scenario
Maria is a cashier. A customer at Table 5 wants:
- 2 Espressos (medium)
- 1 Croissant
- 1 Sandwich (no onions)

She:
1. Clicks Orders → Create Order
2. Selects "Dine-In"
3. Chooses Table 5
4. Adds 2 Espressos (medium)
5. Adds 1 Croissant
6. Adds 1 Sandwich with note "no onions"
7. Reviews total: 75 ILS
8. Customer pays with cash (100 ILS)
9. System shows change: 25 ILS
10. Receipt prints
11. Customer gets receipt and order placed

#### Tips for Success
- Double-check items before saving
- Ask customers about add-ons and preferences
- Use notes field for special requests
- Always confirm payment amount before processing
- Print receipt immediately for customer satisfaction
- For dine-in, verify table number is correct

#### Common Mistakes
- ✗ Forgetting to add all items
- ✗ Wrong table selection
- ✗ Wrong payment amount entered
- ✗ Not selecting correct variants/sizes
- ✗ Creating order without adding items

#### Troubleshooting

**Problem: Can't find a menu item**
- Solution: Check if item is marked as "Active" in menu settings
- Solution: Search by item name if available
- Solution: Ask manager if item is currently available

**Problem: Order won't save**
- Solution: Make sure at least one item is added
- Solution: Check if all required fields are filled
- Solution: Refresh page and try again

**Problem: Can't process payment**
- Solution: Verify payment amount is entered
- Solution: Check internet connection
- Solution: Try different payment method

### FEATURE 2: GUEST ORDERING VIA QR CODE

#### Purpose
Let customers order directly from their table using their phone. No staff needed to take the order.

#### Who Can Access
- Any customer with a phone that can scan QR codes
- No login required
- Available 24/7

#### Step-by-Step: For Customers Using QR Code

**Step 1: Scan the QR Code**
1. Customer sits at the table
2. Finds the QR code (on table, wall, or receipt)
3. Opens phone camera or QR code app
4. Points at QR code
5. Clicks the link that appears

**Step 2: Browse the Menu**
1. Menu appears on their phone
2. Menu is organized by category (Drinks, Food, Desserts, etc.)
3. Customer can:
   - Scroll through items
   - Search by name
   - Filter by category
   - View item descriptions and prices

**Step 3: Select Items**
1. Click on an item to see details
2. See item name, description, and price
3. Choose quantity (how many)
4. Select size or variant if available
   - Example: Coffee size (Small/Medium/Large)
5. Select add-ons (extras to add)
   - Example: Extra shot, vanilla syrup, etc.
6. Add special request notes (optional)
   - Example: "Extra hot", "No whipped cream"
7. Click "Add to Cart"

**Step 4: Continue Shopping**
- Add more items by repeating Step 3
- Or click "View Cart" to see selected items
- In cart, can:
  - Increase/decrease quantity
  - Remove items
  - See running total

**Step 5: Checkout**
1. When done shopping, click "Place Order"
2. Enter customer name (optional)
3. Add special requests for whole order (optional)
4. Review total amount
5. Click "Place Order" button
6. Confirmation message appears

**Step 6: Wait for Food**
1. Customer gets confirmation on their phone
2. Kitchen receives the order
3. Order appears in staff's screens
4. Customer waits at table
5. Staff brings food when ready

#### Expected Results
- Order appears in kitchen/staff screens immediately
- Order total is calculated automatically with correct pricing
- Extras and add-ons are included in total
- No errors from miscommunication
- Fast service since order is prepared immediately

#### Example Scenario
Ahmed sits at Table 3. He:
1. Scans the QR code with his phone
2. Sees the menu in English
3. Searches for "Espresso"
4. Clicks on "Espresso" item
5. Selects "Medium" size
6. Adds "Extra Shot"
7. Adds notes "No foam"
8. Clicks "Add to Cart"
9. Continues adding a pastry
10. Reviews cart total: 42 ILS
11. Enters his name "Ahmed"
12. Clicks "Place Order"
13. Gets confirmation
14. Waits for staff to bring coffee

#### Tips for Success
- Place QR codes where they're easy to see
- Make sure QR codes link to the correct menu
- Test QR codes regularly to ensure they work
- Provide clear instructions if customers ask for help
- Monitor orders coming in to manage kitchen flow

#### Common Issues for Customers
- QR code won't scan
  - Solution: Check QR code is not damaged
  - Solution: Try different phone camera angle
  - Solution: Use dedicated QR code app

- Menu won't load
  - Solution: Check internet connection
  - Solution: Try refreshing the page
  - Solution: Clear browser cache

- Order won't place
  - Solution: Make sure at least one item is selected
  - Solution: Check internet connection
  - Solution: Try again after waiting a few seconds

#### For Staff: Managing QR Orders

**When you see an order from QR:**
1. It will be marked as "Self Order" or "From Table"
2. Check table number for dine-in
3. Follow normal order fulfillment process
4. Bring food to correct table
5. Collect payment if not already paid via QR

### FEATURE 3: RECEIPT MANAGEMENT

#### Purpose
Receipts prove that a customer paid for their order. They can be printed, emailed, or exported as PDF.

#### Who Can Access
- Cashiers can print and view receipts
- Managers can view and manage all receipts
- Administrators have full access

#### Step-by-Step: Print a Receipt After Order

**Immediately After Payment:**
1. After customer pays, receipt screen appears
2. Click "Print" button
3. Printer dialog opens
4. Select your printer from the list
5. Click "Print" to send to printer
6. Printer produces receipt

**To Find an Old Receipt:**

1. Go to **Receipts** in the sidebar
2. You'll see a list of all receipts with:
   - Receipt number
   - Table number
   - Order details
   - Total amount
   - Payment method
   - Date and time

**Using Filters to Find Receipts:**

1. Use the search fields at the top:
   - **Receipt #:** Enter receipt number to find it
   - **Table:** Enter table number
   - **Payment Method:** Select cash, card, wallet, or online
   - **Date Range:** Select From and To dates
   - Click "Search"

2. Results show matching receipts

**Viewing Receipt Details:**

1. Click "View" button on any receipt
2. A detailed receipt opens showing:
   - Customer name
   - Table number
   - Items ordered with prices
   - Subtotal
   - Tax amount
   - Service charge (if any)
   - Discounts applied
   - Final total
   - Payment method
   - Receipt number
   - Timestamp

**Printing a Receipt from History:**

1. Find the receipt in the list
2. Click "Print" button
3. Printer dialog opens
4. Select printer and print

**Exporting Receipt as PDF:**

1. View the receipt (click View)
2. Click "Export as PDF" or "Download PDF"
3. File saves to your computer's Downloads folder
4. Can email this PDF to customer

#### Expected Results
- Receipt prints immediately on thermal printer
- Receipt shows all order details clearly
- Totals are accurate
- Receipt can be emailed to customer
- Receipt is permanently stored in system

#### Example Scenario
Layla is a cashier. After completing an order:
1. Receipt appears on screen with items
2. She clicks "Print"
3. Receipt prints on the printer
4. She gives receipt to customer
5. Later, customer calls to ask about their receipt
6. Layla goes to Receipts page
7. Searches for the date range and table number
8. Finds the receipt
9. Clicks "Export as PDF"
10. Emails PDF to customer

#### Tips for Success
- Check printer is turned on before printing
- Load receipt paper regularly
- Keep receipt rolls in stock
- Verify printer settings match your paper size
- Test print periodically to ensure quality

#### Common Mistakes
- ✗ Forgetting to print before closing register
- ✗ Printing to wrong printer
- ✗ Losing paper receipts
- ✗ Wrong receipt number entered when searching

#### Troubleshooting

**Problem: Receipt won't print**
- Solution: Check if printer is turned on
- Solution: Verify printer is connected to network
- Solution: Check if receipt paper is loaded
- Solution: Try printing test page from printer

**Problem: Can't find a receipt**
- Solution: Use correct date range in filter
- Solution: Search by different criteria (table number instead of date)
- Solution: Check if receipt might be under different time period

**Problem: Printed receipt is faded**
- Solution: Check receipt paper quality
- Solution: Clean printer heads (check printer manual)
- Solution: Ensure paper is not too old

### FEATURE 4: TABLE MANAGEMENT

#### Purpose
Manage your restaurant's tables, track which are occupied, and view their orders.

#### Who Can Access
- Managers can create, edit, and manage tables
- Administrators have full access
- Cashiers can view table status but cannot create/edit

#### Step-by-Step: Create a New Table

1. Click **Tables** in the sidebar
2. Click **"Add Table"** button
3. Fill in the form:
   - **Table Number:** The table's number (e.g., 1, 2, 3... or A1, B2, etc.)
   - **Capacity:** How many people can sit (e.g., 4, 6, 8)
   - **Status:** Set to "Available"
   - **Location:** Where is the table? (e.g., "Window", "Outdoor", "Corner")
   - **Notes:** Any special info (e.g., "High chairs available", "Wheelchair accessible")
4. Click **"Save"**

#### Expected Results
- Table appears in the tables list
- Table can now be assigned to orders
- Customers can scan QR code at the table to order

#### Editing a Table

1. Go to **Tables**
2. Find the table in the list
3. Click **"Edit"** button
4. Change any details (capacity, location, notes)
5. Click **"Save"**

#### Table Statuses

Each table shows its current status:

| Status | Meaning | What You Should Do |
|--------|---------|-------------------|
| **Available** | Table is empty and ready for customers | Customers can be seated |
| **Occupied** | Customers are currently using the table | Don't seat anyone else here |
| **Reserved** | Table is reserved for future customers | Don't seat others here |

#### Viewing Table Orders

1. Go to **Tables**
2. Click on a table name
3. See the current order (if any) for that table
4. See previous orders at that table
5. Can click on any order to see details

#### Example Scenario
Manager Fatima needs to add a new table:
1. Clicks Tables
2. Clicks "Add Table"
3. Enters:
   - Table Number: 8
   - Capacity: 4 people
   - Status: Available
   - Location: Outdoor
   - Notes: "Great view of street"
4. Clicks Save
5. Table 8 now appears in the list

#### Tips for Success
- Organize tables logically (1-10, A-H, etc.)
- Update capacity based on actual seating
- Mark special features in notes
- Mark tables as reserved early if needed
- Keep location descriptions simple and clear

#### Common Mistakes
- ✗ Creating tables with same number
- ✗ Assigning wrong capacity
- ✗ Forgetting to update status when customers leave
- ✗ Creating too many tables

#### Troubleshooting

**Problem: Can't find a table in the list**
- Solution: Scroll down in the table list
- Solution: Search/filter if available
- Solution: Verify table number you're looking for

**Problem: Table status is wrong**
- Solution: Click Edit and change status manually
- Solution: Update status when order is completed

3. **Variants** - Choices within an item (size, flavor)

#### Step-by-Step: Create a Menu Category

1. Click **Menu** in the sidebar
2. Look for **Categories** section
3. Click **"Add Category"**

   - **Category Name:** e.g., "Espresso Drinks"

1. Click **Menu** in the sidebar
2. Click **"Add Item"**

   - **Description:** What is it? (optional)
   - **Image:** Upload a photo (optional)

4. Click **"Save"**

#### Adding Variants to an Item

Variants are different options for the same item (e.g., sizes).

1. Find the item in the menu
2. Click **"Edit"**
3. Look for **Variants** section
4. Click **"Add Variant"**
5. Enter:
   - **Variant Name:** e.g., "Medium"
   - **Price Adjustment:** How much more? (e.g., +5 for medium, +10 for large)
6. Click **"Save"**

#### Adding Add-ons to an Item

Add-ons are extras customers can purchase (e.g., extra chocolate, extra shot).

1. Find the item in menu
2. Look for **Add-ons** section
3. Click **"Add"** or **"Select Add-ons"**

5. Click **"Save"**

#### Creating Add-ons

2. Find **Add-ons** section
3. Click **"Add Add-on"**
4. Enter:
   - **Add-on Name:** e.g., "Extra Shot"

5. Click **"Save"**

#### Managing Item Availability

To make an item temporarily unavailable:
1. Click **Menu**
2. Find the item
3. Click **"Edit"**
4. Toggle **"Active"** to OFF
5. Click **"Save"**
6. Item won't appear in customer menus

To make it available again:
1. Toggle **"Active"** back to ON
2. Save

- Upload clear product images

### FEATURE 6: PAYMENTS & INVOICES

#### Purpose
Process customer payments accurately using various payment methods.

#### Who Can Access
- Cashiers can process payments
- Managers can view payment history
- Administrators have full access

#### Payment Methods Supported

Your system accepts four payment types:

1. **Cash** - Customer pays in physical money
2. **Card** - Credit/debit card payment
3. **Wallet** - Digital wallet (Apple Pay, Google Pay, etc.)
4. **Online** - Online payment processing

#### Step-by-Step: Process a Payment

**For Cash Payments:**

1. Order total is displayed
2. Customer gives you cash
3. Click "Process Payment"
4. Select **"Cash"** as payment method
5. Enter amount customer gave you
6. System calculates change
7. Verify change amount with customer
8. Click **"Confirm Payment"**
9. Receipt generates automatically

**For Card Payments:**

**Q1: What is COMMA?**
A: COMMA is a restaurant Point of Sale (POS) system that helps you manage orders, tables, menu items, payments, and view business analytics.

**Q2: Who uses COMMA?**
A: Cashiers create orders and process payments. Managers oversee operations and view reports. Administrators manage users and system settings. Customers order via QR codes.

**Q3: What payment methods does COMMA accept?**
A: Cash, credit/debit cards, digital wallets (Apple Pay, Google Pay), and online payment processing.

**Q4: What currency does COMMA use?**
A: Currently set to ILS (Israeli Shekel). Administrators can adjust in settings.

**Q5: Is COMMA available in Arabic?**
A: Yes! You can toggle between English and Arabic using the language button in the top menu.

**Q6: Can I use COMMA on my phone?**
A: Yes, for customers to order via QR. Staff use the web version on computers.

**Q7: Does COMMA work offline?**
A: No, COMMA requires internet connection to function.

**Q8: How do I backup my data?**
A: System automatically backs up data. Contact administrator for specific backup details.

### Order & Payment Questions

**Q9: How do I create an order?**
A: Click Orders → Create Order → Select order type → Add items → Process payment.

**Q10: Can customers order from tables?**
A: Yes! They scan QR code at table and order directly from their phone.

**Q11: What if customer wants to cancel order?**
A: If order not started: delete it. If in progress: contact kitchen. If completed: process refund.

**Q12: How do I process a refund?**
A: Find original order → Click Refund → Enter refund amount → Refund returns to original payment method.

**Q13: Can I accept partial payments?**
A: Yes, you can process payment in installments, though system typically handles full payment at once.

**Q14: What if customer loses their receipt?**
A: You can reprint anytime from Receipts page using receipt number, date, or customer details.

**Q15: Can I change a price after order created?**
A: No, prices lock when order placed. For future orders, edit in menu settings.

### Menu & Item Questions

**Q16: How do I add new menu items?**
A: Menu → Add Item → Fill details → Select category → Save. Item appears in menus.

**Q17: Can I have item variants (sizes)?**
A: Yes! Edit item → Add Variant → Set name and price adjustment (e.g., +5 ILS for large).

**Q18: What are add-ons?**
A: Extras customers can add for extra cost (e.g., extra shot in coffee = +3 ILS).

**Q19: How do I temporarily hide a menu item?**
A: Edit item → Toggle "Active" OFF → Save. Item won't appear in menus.

**Q20: Can I upload item images?**
A: Yes! When creating or editing item, upload image. Improves customer ordering experience.

### Table & Shift Questions

**Q21: How do I manage tables?**
A: Tables → Create/Edit/Delete tables. Set capacity, location, and status.

**Q22: What does table status mean?**
A: **Available** = empty and ready. **Occupied** = customers using it. **Reserved** = saved for later.

**Q23: How do I open a shift?**
A: Shifts → Open Shift → Enter opening cash amount → Open.

**Q24: How do I close a shift?**
A: Close Shift → Enter actual cash count → System calculates difference → Close.

**Q25: What if cash doesn't match at end of shift?**
A: Document the variance, report to manager. Common causes: change mistakes, missing transactions.

### Reports & Analytics Questions

**Q26: How do I view daily report?**
A: Reports → Daily Reports → Select date → View. Shows revenue, orders, payment breakdown.

**Q27: Can I export reports?**
A: Yes! Click "Export PDF" on any report. Downloads to your computer.

**Q28: How far back can I view reports?**
A: From system start date. System stores all historical data.

**Q29: What does "Average Order Value" mean?**
A: Total revenue divided by number of orders. Example: 3,500 ILS ÷ 42 orders = 83 ILS per order.

**Q30: How often do reports update?**
A: Automatically as orders complete. Dashboard updates in real-time.

### Settings & Administration Questions

**Q31: How do I change business information?**
A: Settings → Business Information → Update details → Save.

**Q32: How do I customize receipts?**
A: Settings → Receipt Settings → Add logo, footer text, etc. → Save.

**Q33: How do I adjust tax rate?**
A: Settings → Financial → Set tax percentage → Save. Applies to future orders.

**Q34: Who can create user accounts?**
A: Only administrators can create, edit, or delete user accounts.

**Q35: How do I change my password?**
A: Settings → Account → Change Password → Enter current password → Enter new password → Save.

### Troubleshooting Questions

**Q36: Payment failed, what do I do?**
A: Check internet, verify amount, try again. If still fails, use different payment method or try later.

**Q37: Receipt printer won't print**
A: Verify printer is on and connected. Check paper loaded. Restart printer if needed.

**Q38: Order total seems wrong**
A: Check item prices, quantity, tax percentage, and discounts. Contact manager if error found.

**Q39: System is running slowly**
A: Check internet speed. Close extra browser tabs. Refresh page. Try different browser.

**Q40: I don't have permission to do something**
A: Your user role limits access. Ask your manager or administrator for elevated permissions.

## GLOSSARY

### Business Terms

**Add-on / Extra**
An optional item customers can add to their order for an additional cost. Example: extra shot of espresso (+3 ILS).

**Average Order Value**
The average amount each customer spends. Calculated by: Total Revenue ÷ Number of Orders.

**Dine-In**
Customer eating at a table in your restaurant.

**Delivery**
Food delivered to customer's home or location.

**Discount**
Money off the order. Can be fixed amount (e.g., -5 ILS) or percentage (e.g., -10%).

**Invoice**
Official record of a payment transaction. Shows what was paid for and how much.

**Menu Item**
A product you sell (e.g., Cappuccino, Sandwich).

**POS (Point of Sale)**
The system that processes orders and payments. COMMA is your POS system.

**QR Code**
Square barcode that stores table information. Customers scan with phone to access menu.

**Receipt**
Physical or digital proof of payment. Shows what was bought and how much paid.

**Revenue**
Money made from selling items.

**Service Charge**
Extra percentage added to order for service. Example: 10% service charge.

**Takeaway**
Customer purchasing food to eat elsewhere (not at a table).

**Tax**
Government-required percentage added to order. Example: 17% VAT.

**Variant**
A version of an item with different characteristics. Example: Coffee sizes (Small/Medium/Large).

**Void**
To cancel or remove an item from an order.

### System Terms

**Active / Inactive**
Active = item is available for ordering. Inactive = item is hidden from menus.

**Dashboard**
Main screen showing overview of daily business metrics.

**Filter**
Tool to narrow results (e.g., show only cash payments).

**Log In**
Enter username and password to access the system.

**Password**
Secret code to access your account (never share!).

**Refresh**
Reload page to get latest data.

**Role**
Your position type (Cashier, Manager, Admin) which controls what you can do.

**Session**
The time period from login to logout.

**Shift**
Work period from opening to closing (e.g., 8 AM to 8 PM).

**Status**
Current state of something (e.g., order status = "Open").

**Sync / Synchronize**
System updating all locations with latest data.

**Transaction**
A single buy/sell event (one order placed and paid).

**Validate / Validation**
System checking that information is correct before saving.

### Order Status Terms

**Open**
Order created but not started yet.

**Confirmed**
Order received and acknowledged by kitchen.

**Preparing**
Kitchen actively making the order.

**Ready**
Food is prepared and waiting to be delivered.

**Completed**
Customer received food (not necessarily paid yet).

**Paid**
Order fully paid for. Receipt generated.

**Cancelled**
Order cancelled before completion. Money refunded if paid.

**Refunded**
Money returned to customer.

### Role Terms

**Admin (Administrator)**
Person with full system access. Creates users, changes settings, troubleshoots issues.

**Cashier**
Employee who creates orders, processes payments, and prints receipts.

**Manager**
Supervisor who oversees operations, manages menu/tables, and reviews reports.

## EXECUTIVE SUMMARY

### COMMA System Overview (10-Minute Understanding)

**What is COMMA?**
COMMA is a restaurant management system that handles orders, payments, receipts, menu management, and business analytics.

**Who Uses It?**
- **Customers:** Order via QR code on their phone
- **Cashiers:** Create orders, process payments, print receipts
- **Managers:** Oversee operations, manage menus, view reports
- **Admins:** Control entire system and users

**Three Main Activities:**

1. **ORDERING**
   - Customers scan QR code → select items → place order
   - Or cashier creates order at counter
   - Order goes to kitchen immediately
   - Kitchen prepares food

2. **PAYMENT**
   - Customer pays (cash/card/wallet)
   - Amount recorded
   - Receipt prints automatically
   - Change calculated automatically

3. **BUSINESS INSIGHTS**
   - Dashboard shows daily sales
   - Reports show weekly/monthly performance
   - Track top items, revenue, customers
   - Make data-driven decisions

**Key Features at a Glance:**

| Feature | What It Does | Who Uses It |
|---------|--------------|------------|
| **QR Ordering** | Customers order from table | Customers |
| **Dine-In/Takeaway** | Different order types | Cashiers |
| **Multiple Payments** | Accept cash, card, wallet | Cashiers |
| **Receipts** | Generate and print receipts | Everyone |
| **Menu Management** | Update items and prices | Managers |
| **Table Management** | Manage seating | Managers |
| **Reports** | View business metrics | Managers |
| **Shift Management** | Track work shifts | Managers |
| **Analytics** | Understand performance | Managers |
