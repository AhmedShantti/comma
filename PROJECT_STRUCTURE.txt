================================================================================
                      FILE ORGANIZATION LOGIC
================================================================================

WHY THIS STRUCTURE?

Components in one folder:
  ✓ Easy to find related files
  ✓ Clear what's part of shifts dashboard
  ✓ Easy to copy/move feature
  ✓ Self-contained module

Hooks in subfolder:
  ✓ Custom hooks together
  ✓ Easy to extend
  ✓ Clear data layer

API in lib/api:
  ✓ Shared across app
  ✓ Reusable client
  ✓ Easy to mock for tests

Config files in component folder:
  ✓ Close to usage
  ✓ Easy to update
  ✓ Scoped to feature

Documentation in root:
  ✓ Easy to find
  ✓ Visible to all developers
  ✓ Global project context
