================================================================================
  🆘 QUICK TROUBLESHOOTING
================================================================================

"psql command not found"
  → See: DATABASE_SETUP.md, Troubleshooting section

"Connection refused"
  → PostgreSQL service not running
  → Windows: services.msc → find postgresql-XX → Start

"Port 3000 already in use"
  → Change PORT in .env file to 3001

"Password authentication failed"
  → Check your PostgreSQL password in .env matches installation

"Cannot find module"
  → Run: npm install

Need more help?
  → See: TROUBLESHOOTING section in your chosen guide
  → Check: APPLICATION_STARTUP.md Common Issues
